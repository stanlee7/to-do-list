# 할 일 목록 (Simple To-Do List)

깔끔하고 군더더기 없는 반응형 할 일 관리 웹 애플리케이션입니다.

## ✨ 주요 기능
- **할 일 추가**: 텍스트 입력 후 `Enter` 또는 `추가` 버튼 클릭
- **체크 및 완료**: 0.2초 트랜지션과 함께 완료된 항목은 목록 하단으로 자동 정렬
- **삭제**: 마우스 오버 시 선명해지는 삭제 버튼으로 항목 제거
- **필터링**: 전체 / 진행 중 / 완료됨 탭별 조회
- **중복 방지**: 이미 등록된 할 일 입력 시 알림 안내
- **실시간 남은 개수**: 하단 상태 바에서 실시간 남은 할 일 수 확인
- **로컬 저장**: 브라우저 `localStorage`를 통해 새로고침 후에도 데이터 유지

## 🛠️ 기술 스택
- HTML5
- CSS3 (System Sans-Serif, Card Layout, Responsive Design)
- Vanilla JavaScript
